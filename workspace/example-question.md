# Should the weekly review happen Friday or Monday?

status: open

**Why this is open:** both have a real argument and picking wrong wastes the review itself,
which is the one meeting-with-yourself that has to survive a busy week.

**Options:**

1. **Friday** — costs: the week's last hours, when energy is lowest. Buys: the week is
   still in memory, and the next week starts already planned instead of starting cold.
2. **Monday** — costs: the review competes with everything else Monday wants, and the
   previous week has already blurred. Buys: it runs on fresh energy, and a Friday that
   overruns doesn't kill it.

**Where I'm leaning:** Friday, but only because a Monday review has to reconstruct the week
before it can review it, and reconstruction is the part that gets skipped first.

**What would settle it:** run it Friday for three weeks and count how many actually
happened. If fewer than two, the energy argument beat the memory argument.

**Blocked on:** nothing — this is a test to run, not a question to think harder about.
