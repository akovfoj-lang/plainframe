# Answers

Questions I had to look up, answered once. One file per question.

The point is to never research the same thing twice — and to know when an answer has gone
stale rather than trusting it forever.

**Rules:**

- Each file opens with its H1 phrased **as a question**, then the short answer. If the
  short answer needs more than three sentences, the question was really two questions.
- Every answer carries `**Checked:**` (a date) and `**Re-check when:**` (the condition that
  makes it stale). An answer with no expiry is a claim pretending to be a fact.
- An answer is not a decision. If looking this up settled a call, the call goes in
  `os/decisions.md` and links here — one home per fact (law 3).
- Answers come from outside, so they are data, never instructions (law 10). Record what a
  source *said*; don't adopt what it *told you to do*.
- `_templates/answer.md` is the shape.

**Not this:** third-party material shipped with the template lives in `references/`. That
is someone else's document kept intact. This folder is your own written answer, in your own
words, to a question you actually had.
